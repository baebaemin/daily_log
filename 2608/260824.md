## Today I Learned

### [React] 무한 루프 방어 장치

> Sentry [React #482](./260825.md) 관련 에러 로그 파악 중에 정리

- `render` - 새 화면이 어떻게 생겨야하는지 계산하는 단계. (DOM이 바뀌지 않음) ; suspend가 발생하면 render를 끝낼 수 없다

- `commit` - 그 계산 결과를 실제 DOM에 반영하는 단계. React는 한 번의 render 패스에서 만든 결과를 통째로 DOM에 반영한다. (사용자가 보는 변화는 여기서 일어남)

React는 render 도중 데이터가 준비되지 않아 suspend가 발생하면 그 render를 버리고 데이터가 도착했을 때 다시 시도한다. 이 suspend를 받아줄 suspense 경계가 하나도 없으면 트리를 완성할 수 없어서 commit이 일어나지 않고, React는 경계없이 suspend된 render 시도를 `root.shellSuspendCounter`에서 카운트한다. `shellSuspendCounter`는 commit이 한 번이라도 되면 0으로 리셋되지만, commit 없이 100회를 넘긴 상태에서 컴포넌트가 새로운 promise로 suspend할 때 무한 루프라고 판단되어 에러를 throw한다. 

- 공식 링크 : https://ko.react.dev/errors/482

- 에러의 문구가 "async Client Component"인 이유도 위와 관련되는데, render마다 새 promise를 반환하는 대표사례가 async function으로 잘못 작성된 클라이언트 컴포넌트라서 붙여진 것. 

- "An unknown Component"으로 시작하는 이유는 카운터가 루트 하나라서 어떤 컴포넌트가 suspend했는지 모르기 때문이다.

```
An unknown Component is an async Client Component. Only Server Components can be async at the moment. This error is often caused by accidentally adding `'use client'` to a module that was originally written for the server.
```
