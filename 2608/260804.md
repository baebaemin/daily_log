## <br />

### [HTML] ownerDocument ; 모든 노드는 소속 Document가 있다
- DOM의 모든 노드는 자기가 속한 `ownerDocument`를 가지며, 보통은 전부 페이지의 document 하나지만 `template`은 예외다.

```js
const t = document.createElement("template");
t.innerHTML = "<p>안녕</p>"

t.ownerDocument === document    // true (template 태그 자신은 이 문서 소속)
t.content.ownerDocument === document    // false (내용물은 다른 문서 소속)
t.content.ownerDocument.defaultView    // null (window가 없음)
```

- `<template>` 요소가 생성될 때
1. template 요소 생성
2. 그 문서의 inert 문서를 찾음 -> 없으면 새로 만듦 (지연 생성)
3. 그 inert 문서 소속으로 content `DocumentFragment`를 만들어서 붙임 
    - content는 매 template마다 새로 생기고, inert 문서는 Document당 하나만 공유한다.

## <br />

### [HTML] DOM Tree에 포함되지 않는 `<template>`

- `<template>` 안의 내용은 파싱될때 본문 트리(children)가 아니라 template.content라는 별도의 `DocumentFragment`로 들어간다. 
- HTML 파서가 `<template>`의 자식을 자동으로 content 프래그먼트로 빼돌린다. 

```js
const t = document.createElement("template");
t.innerHTML = "<p>안녕</p>";

t.children.length               // 0 (자식 없음)
t.content.children[0]           // <p>안녕</p> (content 안에 있음)

document.body.applendChild(t);  // 문서에 넣었지만
document.querySelector("p")     // null (문서에서 안 잡힘)
document.querySelector("template")  // <template> (태그 자신은 잡힘)
```
