### [Next.js] router.prefetch로 동적 라우트 진입 지연 줄이기 

- data fetching이 원인이 아니더라도 `dynamic()`으로 등록된 아이콘 등 SVG들이 첫 렌더시 비동기 로드되면서 번들 + 컴포넌트 로딩 지연이 발생하곤 한다.

- 지연을 조금이라도 줄이려면 진입 가능성이 높은 페이지를 미리 마운트 시점에 `router.prefetch`로 백그라운드 다운로드 시키기. Next.js의 동적 라우트는 페이지마다 JS 청크가 분리되어 있는데, prefetching시키면 실제 진입 시점에 청크가 이미 캐시되어 있어 지연이 사라진다.
  ```tsx
  useEffect(() => {
    if (siteNo !== null) {
      router.prefetch(recruitRoutes.addLicenseSearch(siteNo));
    }
  }, [siteNo, router]);
  ```

### [Debug] hover 효과를 마우스 환경에서만 적용하기 

- 상황 : 웹앱 개발 중 BottomSheet가 열릴 때마다 첫 옵션이 빠르게 primary 색으로 보였다 사라지는 깜빡임이 발생했다. 

- 원인 : focus-trap 라이브러리가 모달 mount 시 첫 focusable element에 auto-focus를 걸었고, mobile 브라우저에서는 focus 직후 잠깐 `:hover` state도 함께 트리거된 것. 이후 hover가 풀리면서 색이 깜빡임.

- 해결 : `@media (hover: hover) and (pointer: fine)` 가드로 마우스 포인터 환경에서만 hover 효과를 적용한다. [이전에도 대응](../2410/241029.md#debug-mobile-ios-디바이스에서-hover상태에서-벗어났을-경우에도-hover-style이-지속되는-현상)했었던 case라 관련 media mixin을 빠르게 적용해 해결할 수 있었다. 

- 예시 :
```scss
&__option {
  @media (hover: hover) and (pointer: fine) {
    &:hover {
      color: $primary-500;
    }
  }
}
```
