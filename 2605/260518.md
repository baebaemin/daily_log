### [git/Worktree] .gitignore된 폴더는 worktree 생성 시 자동 복사되지 않는다

- Claude Code로 병렬 agents(agent view)를 운영하면서 각 세션별 새 worktree들을 만들었는데, `.specify` 폴더 등이 누락되어 harness가 제대로 동작되지 않았다. `.gitignore`에 등록되어 있는 파일들은 git이 추적하지 않아서 worktree 생성 시 자동으로 같이 따라오지 않았기 때문 🫤

# Git Worktree

## 명명 컨벤션

- **워크트리 경로**: `<WORKTREE_ROOT>/<short-name>` — `<short-name>`은 브랜치의 핵심 식별자만 (`feature/` 접두사 없음, `<WORKTREE_ROOT>`은 프로젝트가 정한 워크트리 루트 디렉토리).
- **브랜치명**: `feature/<short-name>` 등 팀 컨벤션 형식.
- **경로 short-name과 브랜치 short-name은 동일하게 유지**한다. 디렉토리만 보고 어떤 브랜치 작업인지 즉시 식별 가능해야 한다.

## 워크트리 생성

저장소 루트(monorepo root)에서 실행한다.

### 워크트리 초기화

worktree를 작업 루트로 사용하는 경우, 생성 직후 submodule, 의존성, git hook, 하네스 심링크를 초기화한다.

```bash
cd <WORKTREE_ROOT>/<short-name>
git submodule update --init --recursive
yarn install --immutable
node .harness/setup.mjs
```
