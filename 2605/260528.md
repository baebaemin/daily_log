### [Next.js] App Router에서 `router.back()`을 사용하면 스크롤 위치가 자동 복원된다 

- 상황 : 폼의 한 스텝에서 자격증 검색 페이지로 이동했다가 돌아올 때 스크롤이 맨 위로 초기화되어 사용자가 다시 스크롤해야 했다.

- 문제 : 돌아올 경우 `router.push(/back-target)`으로 명시 라우팅하면 새 페이지 진입으로 취급되어 스크롤 복원이 일어나지 않는다.

- 해결 : `router.back()`으로 바꾸면 Next.js App Router가 브라우저의 `scrollRestoration` 기본 동작을 활용해 직전 페이지의 스크롤 위치를 자동 복원한다. 단, 이 패턴은 진입 경로가 단일하다는 보장이 있을 때만 안전하다(history가 비어있는 직접 진입 케이스는 fallback push가 필요).
