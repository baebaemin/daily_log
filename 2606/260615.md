## Today I Learned

### [JavaScript] numeric_ separator 
- JavaScript(ES2021)과 TypeScript에서 지원하는 문법으로, 자릿수를 읽기 쉽게 구분하려고 넣는 시각적 표시.
- 30_000 === 30000 => `true` 값에는 전혀 영향이 없다. 
- 파서가 _를 그냥 무시하며, 컴파일/런타임 결과물도 동일하다. 
- 주의 CASE 
    - _1000 // 맨 앞엔 안 됨
    - 1000_ // 맨 뒤도 안 됨
    - 1__000 // 연속 두개 안 됨
    - 1_.4 // 소수점 바로 옆 안 됨
