### [React Query] enabled:false vs skipToken 

- enabled는 자동 fetch만 off시킨다. 
  - mount시 자동 fetch
  - background refetch (window focus 등)
  - invalidateQueries / refetchQueries에 의한 refetch

- 하지만 queryFn 자체는 멀쩡히 존재하기 때문에 useQuery가 리턴한 refetch()는 수행된다 - 명령형 트리거라서 enabled를 무시함

- skipToken은 enabled 플래그를 조작하는 게 아니라 queryFn 값에 할당하는 방식으로 사용
  ```ts
  import { skipToken, useQuery } from "@tanstack/react-query";

  useQuery({
    queryKey: ["todos", filter],
    // filter가 truthy일 때만 실행되도록. refetch로도 절대 안 돌게 한다
    queryFn: filter ? () => fetchTodos(filter) : skipToken,
  })
  ```
- 단, mount시엔 안 돌리고, 사용자가 액션할 때 처음으로 fetch하는 lazy query의 최초 실행 트리거 용으로는 enabled 토글을 쓰길 권장하고 있다.
- 참고 링크 : https://tanstack.com/query/v5/docs/framework/react/guides/disabling-queries

### [React Query] refetch() 대신 이 방법들을 사용하자 
mutation 후 목록 갱신이나 필터/검색어 변경 재조회 용도로 잘못 쓰이는 경우가 종종 있다. 

1. mutation 성공 후 목록 갱신할 땐 queryClient.[invalidateQueries](../2406/240611.md#react-query-invalidatequeries)를 사용

```ts
const { mutate } = useMutation({
  mutationFn: createWorker,
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['workers'] })
  },
})
```
  - 캐시 전역에서 매칭되는 active(현재 마운트되어 관찰 중인) 쿼리를 모두 처리해야 하는데 refetch()는 해당 useQuery 하나만 갱신한다. 
  
  - mutation을 일으키는 컴포넌트가 그 쿼리를 갖고 있지 않은 경우가 대부분이다. 그래서 onSuccess에서는 refetch 핸들에 접근이 어렵고 prop drilling이 일어날 수 있다. queryClient는 어디서든 꺼내 쓸 수 있으니 이 문제가 없다.

2. 필터/검색어 변경 등 다른 파라미터로 다시 조회 : queryKey 변경 
  - refetch는 파라미터를 못 바꿈. 같은 queryKey, 변수로만 다시 부름.
  - 파라미터가 바뀌면 그 값을 queryKey에 넣자. key가 바뀌면 React Query가 알아서 재조회한다.

  ```ts
  // 필터를 queryKey에 넣으면 자동 재조회 + 조합별 캐싱이 된다
  useQuery({
    queryKey: ["workers", { keyword, area }],
    queryFn: () => fetchWorkers({ keyword, area }),
  })
  ```
  - queryKey는 캐시 식별자이자 의존성 배열이다. 값이 바뀌면 다른 데이터로 간주해 새로 조회하고, 이전 조합은 캐시에 남아 재사용한다.

3. 창 포커스/주기적 갱신 : refetchOnWindowFocus, refetchInterval
  ```ts
  useQuery({
    queryKey: ['dashboard'],
    queryFn: fetchDashboard,
    refetchOnWindowFocus: true, // 탭 복귀시 갱신
    refetchInterval: 30_000, // 30초마다 폴링
  })
  ```

4. 특정 조건 만족 시 자동 실행 : enabled / skipToken
