### [React Query] invalidateQueries

- invalitae = 무조건 전부 즉시 재요청이 아니라 무효화 + 화면에 떠 있는 것만 즉시 갱신. 
- 매칭된 쿼리를 stale로 표시하고, 그중 active(현재 마운트되어 관찰중인) 쿼리만 즉시 refetch한다. inactive 쿼리는 stale 표시만 하고, 다음에 다시 활성화(마운트)될 때 refetch된다. 
- invalidateQueries는 promise를 리턴한다. return invalidateQueries를 하면 state가 업데이트될때까지 loading state가 유지되지만 return을 붙이지 않는다면 mutate 동작이 끝날때까지만 loading state가 유지된다. 
- 참고 링크 : https://developer-alle.tistory.com/439

### [CSS] width, height auto

- 240520에서 작성했던 onImgLoad보다 훨씬훨씬 간편한 방법이 있었다..

```javascript
// Next Image
<Image
  className={cx("content__img")}
  src={`${imgPath}`}
  // onLoad={onImgLoad}
  width={664}
  height={369}
  alt={"상품 미리보기"}
  priority
  unoptimized
/>
```

- width랑 height 특정 값으로 지정해두고 ratio를 유지하면서 지정한 너비와 높이 안에서 렌더링하려면

```scss
.content {
  &__img {
    width: auto;
    height: auto;
  }
}
```

- 이렇게만 해줘도 된다
