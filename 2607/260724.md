## Today I Learned

### [CS] 심링크 symlink ✍️
- 심볼릭 링크 Symbolic Link : 컴퓨터 파일 시스템에서 다른 파일이나 폴더의 경로를 가리키도록 연결해 주는 특수한 형태의 참조 파일

- IDE에서 심링크 파일을 열면 자동으로 경로를 따라가서 대상 파일을 열어주기 때문에, 링크 자체를 보려면 터미널에서 확인해야한다.

```sh
ls -la CLAUDE.md 
# lrwxr-xr-x@ 1 user staff 28 Jun 8 14:56 CLAUDE.md -> .harness/templates/CLAUDE.md

readlink CLAUDE.md # 가리키는 경로만 출력
# .harness/templates/CLAUDE.md

realpath CLAUDE.md # 절대 경로 출력. 실제 파일이 어디 있는지 확인할 때 유용하다.
# /Volumes/www/_goodbuilder/monorepo/.harness/templates/CLAUDE.md
```
