## Today I Learned

### [Debug] 지시문 이탈 디버깅

- 상황 : 구축용 하네스 > 서브에이전트 문서(agents/claude/implementer.md)에 "package.json에서 검증 명령을 찾아 실행하라"고 적어두었는데, 스크립트를 못 찾으면 전역에 설치된 `tsc`/`eslint`를 프로젝트 전체에 임의 실행하는 이탈이 간헐적으로 발생했다. 

- 문제 : 같은 문서에 기재되었던 "검증을 건너뛴 채 완료 보고하지 말라"를 상위 규칙으로 해석해서, 도구를 임의로라도 돌려 검증을 채우려 했던것이 원인.

- 해결 : 충돌하는 두 규칙 사이의 우선순위를 정리해야 한다 > "스크립트가 없으면 검증하지 않아야 하며, 검증 미수행 보고는 실패가 아니라 정상 완료"라고 선언. + `npx`·전역 도구를 사용하지 않도록 보완했다.

- 테스트 : 임의 실행 대신 "필요한 검증 명령을 알려달라"는 질문으로 되돌아옴. 

- 해결 2 : "package.json에서 검증 명령을 찾아 실행하라"는 문장은 범용화를 염두에 두고 작성했던 내용이나, 운영용 하네스를 별도로 구축하자는 의견으로 모아져 명령어를 직접 명시하는 방법으로 깔끔하게 마무리되었다. `yarn {service} run typecheck` 등..>
