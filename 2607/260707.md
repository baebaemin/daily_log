### [Sass/Next.js] sass additionalData로 mixin 전역 주입 
Next.js `next.config`의 sass `additionalData` 옵션에 mixin/변수 파일을 넣으면 빌드 시 모든 module.scss 상단에 자동 주입된다. => 개별 파일에서 import 없이 공용 mixin·토큰을 바로 쓸 수 있다.

```ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  ...,
  sassOptions: {
    includePaths: [designSystemPath],
    additionalData: `
      @use "sass:map";
      @use "sass:meta";
      @use "sass:string";
      @use "sass:math";
      @import "@design-system/styles/base/colors";
      @import "@design-system/styles/abstracts/variables";
      @import "@design-system/styles/abstracts/functions";
      @import "@design-system/styles/abstracts/mixin";
      @import "@/styles/mixin";
      @import "@/styles/theme";
      @import "@/styles/semantic";
    `,
    silenceDeprecations: ["import", "legacy-js-api", "global-builtin", "if-function"],
  },
  ...,
}
```

- 참고 링크 : https://nextjs.org/docs/app/api-reference/config/next-config-js/sassOptions
