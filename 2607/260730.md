### [TIL-WORDS]
- glob pattern : 와일드카드로 여러 파일·디렉터리 경로를 패턴 하나로 매칭하는 문법.

## <br />

### [glob] glob에서 사용하는 와일드카드
- `*` : 한 구간 안에서 아무 이름 (경로 구분자 `/`는 못넣음)
    - apps/* 
        - apps/service (O)
        - apps/service/app (X)

- `**` : 몇 단계든 하위 디렉터리
     - apps/**
        - apps/service (O)
        - apps/service/app (O)

- `?` : 아무 글자 한 개
    - 2607_?.md
        - 2607_1.md (O)
        - 2607_12.md (X)

- `[...]` : 대괄호 안 글자 중 한 개 
    - step[12].tsx
        - step1.tsx (O)
        - step2.tsx (O)

- `[!...]` : 대괄호 안 글자를 제외한 한 개
    - [!.]* : 점으로 시작 안 하는 것들

- `{a,b}`: 나열한 선택지 중 하나
    - *.{ts,tsx}
        - *.ts (O)
        - *.tsx (O)

## <br />

### [monorepo] monorepo =/= workspaces

- monorepo : 여러 프로젝트를 하나의 git repo에 담기로 한 결정
- workspaces : 해당 repo 안에 여러 개의 패키지(package.json)를 두고, 패키지 매니저가 이들을 하나로 관리하게 하는 기능
- workspace : 그렇게 관리되는 패키지 하나하나 (관리 단위) 
    - package.json이 있다면, 루트 자신도 workspace

monorepo는 `결정`이고 workspaces는 그걸 실현하는 `기능`이므로 모노레포라 해서 전부 workspace만으로 이루어진 것은 아니다. 작업중인 모노레포의 경우도 workspace이면서 git 서브모듈인 디자인 시스템, workspace가 아닌 순수 서브모듈인 하네스가 포함되어 있다. (= workspaces + 서브모듈 조합)
