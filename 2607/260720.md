## Today I Learned


### [Testing] vi.useFakeTimers()

- Vitest에서 시간을 가짜로 제어하게 해주는 api를 사용해서 new Date()에 의존하는 로직 등을 fake timer로 시간을 고정할 수 있다. 나이 계산(`calculateAge`)처럼 오늘 날짜에 따라 결과가 달라지는 [flaky](../2602/260218.md#til-words) 로직을 테스트할 때 용이. 

```tsx
// birthDate.test.ts
import { vi, test, expect } from 'vitest'

  describe("calculateAge", () => {
    beforeEach(() => {
      vi.useFakeTimers(); // 타이머 교체
      vi.setSystemTime(new Date("2026-07-20T00:00:00Z")); // 시스템 시간을 2026-07-20으로 고정
    });

    afterEach(() => {
      vi.useRealTimers(); // 테스트가 끝나면 실제 시계로 복원
    });

    it("should return null for invalid birth date format", () => {
      expect(calculateAge("1990")).toBeNull();
      expect(calculateAge(null)).toBeNull();
      expect(calculateAge("")).toBeNull();
    });

    // ... 테스트들 ...
  })
```
