### [HTTP] 응답 헤더
- HTTP 메시지에서 상태줄과 본문 사이에 오는 `필드: 값` line들.

- 요청에 대한 응답의 메타데이터로, 본문 내용 자체가 아니라 그 응답을 어떻게 해석할지 적힌 설명

- HTTP 응답은 대략 세 덩어리다
    1. 상태줄: 200 OK, 404 Not Found 같은 결과 코드
    2. 응답 헤더: 필드:값 목록 (Content-Type, Content-Length, Set-Cookie, Cache-Control 등)
    3. 본문(body): JSON, HTML, 이미지 등의 data

```
HTTP/1.1 200 OK                 // 상태줄
Content-Type: application/json  // 응답 헤더
Content-Length: 14              // 응답 헤더
                                // 빈 줄 = 헤더 끝
{"name":"kim"}                  // 본문
```

- 응답 헤더를 받았을 때
    1. 브라우저가 상태줄과 헤더를 끝까지 수신한다.
    2. 그 정보로 Response 객체를 만든다 (이 시점에 status, ok, headers가 채워진다.)
    3. 그 객체로 fetch() Promise를 resolve한다.
    4. 본문은 아직 도착 중일 수 있고, res.json()이 그것을 기다린다.
        - 헤더 전 실패는 fetch reject, 헤더 후 실패는 body method reject.
